# 🖥️ Настройка AmneziaWG на Windows

Эта инструкция поможет подключить твой конфиг на компьютере с Windows 10 или 11.

## 📥 Что понадобится

1.  **Файл конфигурации** (с расширением `.conf`). Ты должен был сгенерировать его заранее (например, через WARP + скрипт обфускации).
2.  **Установщик AmneziaWG** для Windows.

## 🛠️ Шаг 1: Скачиваем и устанавливаем клиент

1.  Перейди на официальную страницу загрузок AmneziaWG (или используй зеркало, если официальный сайт недоступен).
2.  Скачай установщик для своей версии Windows (обычно это **x64**).
3.  Запусти скачанный файл и следуй инструкциям установщика. Если Windows запросит разрешение, нажми «Да».
4.  После установки открой приложение **AmneziaWG**.

## 📂 Шаг 2: Импортируем конфиг

1.  В открывшемся окне приложения нажми кнопку **«Добавить туннель»** (или «Import tunnel(s) from file»).
2.  Откроется проводник. Найди свой `.conf` файл и выбери его.
3.  Если всё сделано правильно, в списке появится новый туннель с именем твоего конфига.

## 🔌 Шаг 3: Подключаемся

1.  Нажми на кнопку **«Подключить»** (Connect) рядом с названием туннеля.
2.  Статус изменится на «Подключен» (Connected), и появится зелёная галочка.

**Готово!** Теперь весь твой трафик идёт через зашифрованный и замаскированный туннель.

---

### ❓ Если что-то не работает

*   **Ошибка при импорте:** Убедись, что файл имеет расширение `.conf` и внутри нет лишних символов.
*   **Нет подключения:** Проверь, что твой конфиг всё ещё активен (не заблокирован). Попробуй перезапустить приложение.
*   **Не открываются сайты:** Возможно, проблема в DNS. Попробуй в настройках туннеля указать DNS-серверы (например, `1.1.1.1`).
